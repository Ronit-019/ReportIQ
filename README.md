# ReportIQ

**An end-to-end Retrieval-Augmented Generation (RAG) system for document intelligence, evaluation, and observability.**

ReportIQ enables users to ask questions about internal documents and inspect how the RAG pipeline retrieves information and generates answers. It combines a Python backend, a React dashboard, retrieval evaluation, and LangSmith tracing.

## Features

- **RAG Chat:** Ask natural-language questions about the indexed documents and receive answers grounded in retrieved context.
- **Offline Evaluation Dashboard:** Review recorded evaluation metrics and baseline results.
- **Online Observability Dashboard:** Inspect LangSmith traces, request status, latency, model information, token usage, and stage-wise timing.
- **Semantic Retrieval:** Use FAISS vector search with embeddings generated by `BAAI/bge-small-en-v1.5`.
- **LLM Generation:** Generate answers using the Groq API.
- **Document Processing:** Convert PDF documents to Markdown and prepare chunks for retrieval.

## Architecture

- **Frontend:** React, TypeScript, Vite, Recharts
- **Backend:** Python, FastAPI
- **RAG:** LangChain, Hugging Face embeddings, FAISS
- **LLM:** Groq API
- **Tracing:** LangSmith
- **Evaluation:** Recorded baseline results and evaluation scripts

## Local Setup

### Prerequisites

- Python 3.13 or a compatible Python version
- Node.js and npm
- Git
- A Groq API key
- A LangSmith API key for tracing and the online observability dashboard

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ReportIQ
```

### 2. Create a Python environment

```bash
python -m venv venv
```

Activate it in Git Bash on Windows:

```bash
source venv/Scripts/activate
```

Install the Python dependencies:

```bash
pip install -r requirements.txt
```

### 3. Configure environment variables

Create a local `.env` file in the project root. Add your own credentials:

```dotenv
GROQ_API_KEY=your_groq_api_key
LANGSMITH_API_KEY=your_langsmith_api_key
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=ReportIQ
```

Never commit `.env` or publish API keys.

### 4. Prepare the vector store

The RAG pipeline expects these local artifacts:

```text
data/processed/vectorstores/
├── v3_locked.faiss
└── v3_locked_chunks.pkl
```

These generated files are excluded from Git. Obtain the matching artifacts separately or regenerate them using the project's ingestion, chunking, embedding, and vector-store scripts before starting the backend.

### 5. Start the backend

From the project root:

```bash
python -m uvicorn backend.main:app --reload
```

The API is available at `http://127.0.0.1:8000`.

Useful endpoints:

- `GET /api/health` — health check
- `GET /api/evaluations` — recorded offline evaluation results
- `GET /api/traces` — LangSmith trace data
- `POST /api/chat` — submit a RAG question

### 6. Start the frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite.

## Evaluation

ReportIQ includes recorded baseline evaluation results under `evaluation/results/`. The golden evaluation dataset is still under development and is not included in this repository.

Reported evaluation metrics describe the recorded baseline and should not be interpreted as guaranteed performance across all documents or queries.

## Observability

The online dashboard reads traces from the configured LangSmith project and displays request status, question and answer, model, token usage, trace duration, and embedding, retrieval, and generation timings.

Automatic refresh is configured in the frontend. LangSmith tracing and the backend must be configured correctly for live data to appear.

## Deployment

Deployment is planned with a hosted FastAPI backend and a hosted React frontend. Deployment configuration and environment-specific API settings will be documented after deployment has been verified.

Local development should continue to use the local FastAPI backend and local environment variables.

## Security Notes

- Keep API keys in environment variables, never in source control.
- Do not commit `.env`, local databases, virtual environments, or generated vector-store artifacts.
- The included source PDFs are synthetic documents prepared for this project.
